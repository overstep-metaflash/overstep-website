`e91d462b6990880b64dc9311aebfca73babbcc75f790e8258426184c1d90d2fe`).

or image recompression is applied. This supersedes the dedicated-banner decision
in `SIDEBAR.md`.

category and other lists. Article titles remain visible. The SWF download link
is removed from the shortcode HTML and `showSwfDownload` is explicitly false for

options do not guarantee warning-free silent initialization. Visual autoplay is
preserved, with the unmute overlay available when a gesture is needed. No warning
suppression, browser security changes, or undocumented runtime patches were used.
The source and Context7 `/ruffle-rs/ruffle` documentation were checked for audio
and autoplay configuration. Actual Firefox audio playback was not reproduced.
