# Public content and media audit

Date: 2026-11-16. Site baseline: `dee734d6f02e5428d69475147f32904ea49aeba8`.

This audit covers all 470 published articles, their corresponding saved HTML
pages, the public comment dataset, and the specific backup media referenced by
those articles or the legacy radio. Draft content and private contact fields are
excluded. The XML, SQL and FTP backups were not modified; archived PHP and Flash
code were not executed. No article cleanup or website deployment is performed by
this audit.

## Injected links

Each flagged article contains one unrelated link. Promotional, sexual, dating and
gambling anchor text appears inside unrelated prose or above artwork. All 78
links are present in the XML export. Matching saved HTML exists for every public
article: 29 flagged links are absent from the corresponding older copy, while
49 are already present there. A bulk restore from the HTML cache would preserve
many injections.

This finding classifies specific link instances by their anchor/context and
source comparison. It is not a live reputation verdict about whole domains.
Destination sites were not visited. Examples include unrelated links in
`inspiration`, `i-live-in-amazonie`, `jour-38-la-fin-dun-corps`, and the Totem post.
Legitimate artist attributions and the original `porn-industry` article must not
be removed by a naive keyword filter.

The 2,639 sanitized comment bodies have no link to the 30 article-spam hosts.
This targeted check is not a complete editorial spam review of comments, author
URLs, or historical blogroll destinations.

See [all affected links and source files](2026-11-16-links.csv). The JSON evidence
also records snapshot presence and exact link instances. Review and remove the
injected anchor text as well as its hyperlink, repairing interrupted sentences
only where the original wording is supported by evidence.

## Original Flash media

The 124 absent Flash players represent 124 distinct original movie paths:

- 117 are explicitly embedded in the XML article bodies.
- Seven appear only in the older article HTML and are already absent from the
  exported body.
- 116 movie files already exist under `static/`, but their article integrations
  are missing.
- Eight movie files have not yet been copied into the public assets.
- Every movie has one or more backed-up file candidates. Ten basenames have
  multiple different hashes and require exact-path/source selection.

There are 15 entirely empty Hugo article bodies; 12 correspond to this Flash
finding. Counting article URLs and HTTP-available files did not detect the lost
embeds. Recovery must compare original article/media associations against
rendered players, not just file existence.

The eight uncopied movies are `work2.swf`, `arbre.swf`, `electropanik.swf`,
`approche.swf`, `jour-6.swf`, `jour-17.swf`, `day6.swf` and `day15.swf`. Their
article paths, original URLs, backup candidates and SHA-256 hashes are recorded
in the evidence. These are recoverable candidates, not files already restored
to the site by this audit.

See [the 124 article/movie associations](2026-11-16-flash.csv).

## Radio and owner audio decision

The owner confirmed use of non-radio MP3 files and requested a Spotify or Deezer
playlist for the old radio. This is recorded as `confirmed_by_owner` for the 45
tracked audio files in `../media-rights.json`. It records the owner's instruction
rather than an independent licensing assessment.

The radio backup has 17 MP3 files under `backup_ftp/www/radio/mp3/`.
`radioconfig.php` builds a sorted list from that directory; it was read as text.
None of these 17 file hashes matches the 45 tracked MP3s. The radio directory is
not present in the public site. Its original track identifiers, sizes and hashes
are included in the JSON evidence for playlist reconstruction. Availability and
recording/remix matches on Spotify or Deezer remain unverified.

Decompressed string data in `static/theme/step/menu.swf` points to
`http://www.overstep.fr/radio/`. The migrated `/radio/` page is missing. The ticket
therefore includes both the playlist and navigation repair. No original radio
MP3 should be imported as part of that work.

## Historic URLs and release state

The remaining non-radio local gaps are the Semelles attachment route, an old
Dotclear `index.php` comment link, a malformed `liens.html)` link, and the Fifth
Axis/emulator ZIP link. The ZIP is present in the backup; restoring a game disk
image/executable requires a deliberate archival decision.

The current `?p=ID` and `/feed/` implementations are browser fallbacks, not HTTP
permanent redirects. They still require production-host and RSS compatibility
review. GitHub Pages, the site-artifact upload and DNS remain unchanged. The
global `publication_approved` field remains false while the radio replacement
and content review are outstanding.

Article media was compared with the public XML bodies and scoped `.entry-content`
from 470 saved HTML pages. Names were normalized and apparent image losses were
cross-checked using file hashes and the actual Hugo-generated article HTML.
Comments were checked only for overlap with the identified article-spam hosts.
Backups were read as data; no SQL import, archived PHP execution, source backup
editing, external playlist creation, live suspicious-domain browsing or manual
Ruffle playback was performed.

The audit's source inventory and findings are documentation/data changes and do
not alter generated site behavior. No new application tests are required for
this audit; implementation tickets require focused regression tests and a
source-to-rendered-media reconciliation.
